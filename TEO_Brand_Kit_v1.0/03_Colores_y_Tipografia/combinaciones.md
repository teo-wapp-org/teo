# Colores y combinaciones

HEX transcritos de las etiquetas del manual. Las muestras raster contienen luz, degradados y compresión; no deben muestrearse como sustituto del HEX escrito.

El manual muestra fondos claros, azul oscuro y verde en los ejemplos de logo correctos. Lila para apoyo y superficies. Verde para acciones y acentos. Mantener las versiones originales y el contraste mostrado; no recolorear el logo.

No hay especificaciones CMYK, Pantone, perfil de impresión ni recetas de degradados. No se declaran equivalencias de impresión.
