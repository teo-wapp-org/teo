# Aplicaciones del manual

- Dashboard: gestión de conversaciones, clientes y ventas.
- Web / Landing: comunicación clara, moderna y orientada a resultados.
- Redes sociales: contenido educativo, productos y novedades.
- Material comercial: presentaciones, folletos, stickers y más.

Se entrega un PNG independiente de cada muestra y el panel completo. Son referencias visuales raster, no sitios funcionales, plantillas de redes editables, mockups por capas ni artes finales de imprenta. No se extrapolan formatos o aplicaciones ausentes.
